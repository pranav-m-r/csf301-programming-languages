# Use Cases for Heterogeneous List Library

This folder contains practical applications demonstrating the capabilities of our Functional-OO heterogeneous list library.

## Use Case 1: Keyword Frequency Counter

**File:** `KeywordFrequency/`

Scans a directory of text files and counts keyword occurrences, outputting them in descending frequency order.

**Features demonstrated:**
- File I/O operations
- HeteroList for storing keyword-count pairs
- Functional operations: map, filter, sort
- Aggregation: frequency counting

**Usage:**
```
KeywordFrequency.exe <data_directory> <keyword_file>
```
